About this tool

      
This app converts a manuscript (PDF, DOCX, DOC or HTML) into TEI XML using
        GROBID, then runs a set of automated meta-scientific quality checks
        against it and produces an HTML report.


      
Where the checks come from

      
    
        
  • metacheck (R package) — the original set of manuscript checks.
          Selected checks are run through the installed R metacheck
          package when the "metacheck (R)" engine is chosen.
    • 
        
  • ChetaMeck — an independent Python reimplementation of the
          metacheck checks (v0.2.2), plus extra modules for forensic metascience,
          effect-size/CI consistency and the R2 editorial assessment.
    • 
        
  • GROBID — the open-source tool that converts PDFs to structured
          TEI XML. It runs on a remote or local server that you select in the
          Run tab.
    • 
      


      
Effect-size & CI consistency

      
The "Effect size & CI consistency" check is a port of the core of
        escicheck (also known as EffectCheck) by Gilad Feldman, available at
        github.com/giladfeldman/escicheck (MIT).


      
How to cite

      
    
        
  • metacheck: cite the metacheck R package and its companion
          paper (see the metacheck documentation / citation("metacheck")).
    • 
        
  • ChetaMeck: this is an independent reimplementation; cite it as
          "ChetaMeck (v0.2.2), a Python reimplementation of the metacheck checks
          for manuscript quality assessment."
    • 
        
  • GROBID: López, P. et al. (2009). GROBID: Combining Automatic
          Bibliographic Data Recognition and Term Extraction for Scholarship
          Publications. ECDL.
    •
